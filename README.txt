SOUTH KOLKATA PANDAL HOPPING WEBSITE
====================================
Files:
- index.html: main website
- style.css: visual design
- script.js: 50 pandal dataset, search, day filters, route tabs

HOW TO OPEN:
1. Extract this ZIP.
2. Open index.html in a browser (Chrome recommended).
3. Internet is only needed for Google Fonts and external map links; the main website itself works offline.

HOW TO PUBLISH FREE:
- GitHub Pages: create a GitHub repository, upload these files, then enable Pages in repository Settings.
- Netlify: upload the extracted folder using Netlify's manual deploy option.

IMPORTANT:
Pandal locations, transport hints and distances are planning estimates. The list is not a verified ranking or live navigation service. Check the exact pandal pin and transport timetable before travelling.

SCORING / ANIMATION UPDATE
--------------------------
- Each completed pandal earns 20 XP.
- Every 100 XP advances one level.
- Ranks progress from Beginner Explorer to Route Explorer, Puja Champion, and Pandal Master.
- Achievement badges unlock at 1, 10, 25, and 50 completed pandals.
- Completion progress is saved in the same browser using local storage.
- This is a client-side score (not a public leaderboard); it stays on the device/browser.

ADVANCED GAME FEATURES
----------------------
- 3D hover tilt effect on pandal cards (desktop pointer).
- XP reward sound made with browser audio; toggle Sound ON/OFF.
- Player name setting and top-10 local leaderboard.
- Leaderboard/high scores are stored in the same browser/device only.
- No online shared ranking until a hosted backend/database is connected.
